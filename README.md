## 🌐 About HACKNOVA

**HACKNOVA Enterprise** is the next-generation autonomous cybersecurity operations and AI penetration testing ecosystem built for modern enterprises, DevSecOps teams, and frontier AI infrastructures.

In an era where adversarial threats evolve in real time, traditional static vulnerability scanners deliver disconnected lists of low-priority noise without actionable context. **HACKNOVA revolutionizes proactive cyber defense** by fusing frontier multi-model artificial intelligence, autonomous multi-stage attack chaining, cloud-native posture auditing (CSPM/KSPM), and OWASP LLM Red Teaming into a unified, high-velocity platform.

Whether evaluating Kubernetes clusters across AWS, Azure, and GCP, auditing enterprise REST/OpenAPI surfaces against zero-day exploit techniques, or stress-testing mission-critical Large Language Models against prompt injections and jailbreaks, **HACKNOVA thinks like an elite adversary to defend like an automated SOC army.**

**Architected & Created by [Yashab Alam](https://github.com/yashab-cyber)**

> 💡 **Community & Mission**: HACKNOVA empowers developers and ethical hackers with transparent, auditable, and automated security tools. Help accelerate research infrastructure and open-weight model integrations: [Support HACKNOVA Development](DONATE.md).

## 🚀 Quick Start

### Prerequisites
- **Operating System**: Linux (Ubuntu/Debian/RHEL/CentOS), macOS, or Windows WSL2
- **Python**: 3.8+ with pip and virtual environment support
- **Docker**: For containerized deployment (recommended)
- **Resources**: Minimum 4GB RAM, 20GB disk space

### Enterprise Installation

```bash
# Clone the repository
git clone https://github.com/alaika-cyber/hacknova.git
cd hacknova

# Run enterprise installer (sets up all services)
chmod +x install.sh
./install.sh

# Configure environment
cp .env.example .env
# Edit .env with your API keys and settings
nano .env

# Verify installation
python3 test_installation.py
```

### OrcaRouter Cyber Inference
[OrcaRouter](https://www.orcarouter.ai) is an OpenAI-compatible gateway for authorized
security teams. It routes scoped security reasoning to the OrcaCyber models and carries
the gateway's blue-team controls on the same endpoint. Select the `orcarouter` provider
(base URL `https://api.orcarouter.ai/v1`) and set `ORCAROUTER_API_KEY`, or
`[ai] orcarouter_api_key` in `config.ini`.

- Recommended default: `orca/orcacyber-ultra-1.0` (OrcaCyber Ultra); `orca/orcacyber-zero-1.5`
  is the harness-driven alternative. Both require the cyber tier to be unlocked for
  your workspace during business verification.
- When the cyber tier is not unlocked, use `orcarouter/fusion`.
- Provider page: https://www.orcarouter.ai/cyber
- Cyber model catalog: https://www.orcarouter.ai/models?tier=cyber

The dashboard's **AI Providers** view accepts the key and loads models from the live
`GET https://api.orcarouter.ai/v1/models?capability=chat` catalog.

### Runcrate
[Runcrate](https://runcrate.ai) serves open-weight models through an OpenAI-compatible
API at `https://api.runcrate.ai/v1`. Set `RUNCRATE_API_KEY` (and optionally
`RUNCRATE_BASE_URL`), then pick a registered model such as
`deepseek-ai/DeepSeek-V4.1-Flash`, `zai-org/GLM-5.3`, `moonshotai/Kimi-K3`,
`Qwen/Qwen3.5-397B-A17B` or `openai/gpt-oss-120b`, or route any other Runcrate model
with the `runcrate/<model>` prefix:

```bash
export RUNCRATE_API_KEY=your_runcrate_api_key
python advance_secscan_ai.py --model deepseek-ai/DeepSeek-V4.1-Flash
```
