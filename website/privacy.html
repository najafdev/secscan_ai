Privacy Policy

REVISION: NOVEMBER 2026

1. Sovereign On-Device Execution

AgentsDroid is designed with an on-device first philosophy. Memory, execution logs, and UI interaction states remain strictly within local encrypted SQLite databases on your Android device. No central telemetry or user monitoring servers exist.

2. Hardware Keystore Encryption

External LLM API keys provided by the user are encrypted using hardware-backed keys via Android Keystore (AES-256 GCM). Keys are kept in memory exclusively during active model generation calls.

3. Accessibility Service Data

The Android Accessibility Service is utilized solely to parse UI element hierarchies for user-directed task automation. UI contents are never transmitted to third parties without explicit instruction.

4. Open Source Auditing

The full source code of AgentsDroid is public under the Apache 2.0 license at github.com/agentsdroid/agentsdroid for verification and security audit.
