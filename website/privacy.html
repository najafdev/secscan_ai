Privacy Policy

Last Updated: November 2026

1. Sovereign On-Device Architecture

AgentDroid is engineered with a strict sovereign privacy-first philosophy. By default, task planning, memory retention, and UI automation logs are kept exclusively within your local Android device's encrypted storage.

2. API Credentials and Hardware Keystore

When you configure external LLM API keys (such as OpenAI, Gemini, Claude, or Groq), they are encrypted using hardware-backed AES-256 GCM keys via Android Keystore. AgentDroid does not maintain third-party telemetry servers to collect your keys.

3. Accessibility Service & Screen Data

The Android Accessibility Service is utilized solely for user-approved autonomous UI interactions. Screen element hierarchies and UI data processed during DAG executions are stored temporarily in volatile memory or local SQLite databases and are never transmitted to external third parties without user direction.

4. Open Source Transparency

AgentDroid is fully open source under the Apache 2.0 license. The complete codebase can be inspected and verified independently at our official repository: github.com/agentsdroid/agentsdroid.
