AgentDroid Technical Documentation

AgentDroid is an Android-native multi-agent system designed to bring autonomous agent orchestration, DAG task resolution, and native UI automation to modern mobile devices.

Prerequisites

  • Android 10.0+ (API level 29 or higher; target API 34)
  • JDK 17 or JDK 21 installed
  • Android Accessibility Service permission (for PhoneControlAgent UI automation)
  • Optional: Local Ollama running on Wi-Fi or Cloud API keys (Gemini, Anthropic, OpenAI, Groq)

Building from Source

Clone the repository and build the project using Gradle:

git clone https://github.com/agentsdroid/agentsdroid.git
cd agentsdroid

# Run test suite
./gradlew testDebugUnitTest

# Build debug APK
./gradlew assembleDebug

DAG Task Scheduler Engine

The core of AgentDroid is the Directed Acyclic Graph (DAG) Scheduler (DAGScheduler.kt). When a user submits an instruction, the Master Agent decomposes it into discrete nodes with dependencies: 

// Example DAG Definition
val taskGraph = TaskGraph(
    root = TaskNode("Decompose Goal", agent = MasterAgent),
    nodes = listOf(
        TaskNode("Research Trends", agent = ResearchAgent, dependencies = listOf("root")),
        TaskNode("Draft Summary", agent = ContentAgent, dependencies = listOf("Research Trends")),
        TaskNode("Approve Action", agent = SecurityEngine, dependencies = listOf("Draft Summary")),
        TaskNode("Post Update", agent = PhoneControlAgent, dependencies = listOf("Approve Action"))
    )
)

Accessibility Service Integration

AgentDroid uses AgentDroidAccessibilityService.kt to inspect node hierarchies and execute accessibility actions (click, scroll, long press, set text). Zero root access is required. All actions pass through the EmergencyKillswitch before dispatch.

5-Tier Memory Architecture

Agent context is managed across five tiers to optimize mobile RAM usage:

  • Sensory Memory: Screen snapshots, incoming notifications, and active UI tree nodes.
  • Working Memory: Ephemeral variables active within a single DAG session.
  • Episodic Memory: Historical task logs stored in Room SQLite with a 30-day retention window.
  • Semantic Memory: Knowledge graphs and user preferences.
  • Procedural Memory: Learned automation macros and UI coordinate templates.

Security & Keystore AES-256 GCM

API keys are protected by SecurePreferencesManager.kt using hardware-backed Android Keystore keys with AES-256 GCM encryption. Plaintext keys are never written to disk.

Configuring Local Ollama

To run sovereign offline agents, connect your device to the same Wi-Fi network as your workstation running Ollama: 

# On your local computer:
OLLAMA_HOST=0.0.0.0:11434 ollama serve

# In AgentDroid app:
Set Endpoint: http://192.168.1.X:11434
Select Model: llama3:8b
