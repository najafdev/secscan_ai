AI Integration Redefined

Features built from the ground up to give you full natural language control over your machine.

🗣️

Natural Language Interface

Type or speak commands directly. OpenOS maps your requests into actions—whether you need to open applications, rearrange windows, or retrieve information.

🧠

100% Local Intelligence

Powered entirely by Ollama. Your data never leaves your machine. Enjoy complete offline capabilities and total control over your personal computing environment.

🛡️

Intelligent Protection

Built-in security rules ensure that destructive or high-risk actions (like deleting system files or formatting partitions) always prompt you for authorization first.

Simple Installation

Set up OpenOS in your current environment or build a custom live ISO.

1. Clone Repository

git clone https://github.com/yashab-cyber/sai-os.git
cd sai-os

2. Install Dependencies

make install-all
make setup-ollama

3. Run OpenOS Shell

make run-shell
