Everything You Need to Know

Answers to common questions regarding deployment, architecture, model data safety, and compliance.

How does SecScan AI compare to legacy vulnerability scanners?

Legacy scanners generate static reports full of false positives and leave remediation to manual human intervention. SecScan AI pairs multi-cloud posture analysis with autonomous AI reasoning (OrcaRouter, Claude, GPT-4o) and MITRE D3FEND mappings, delivering tested, ready-to-merge Terraform and Bash scripts that neutralize flaws in seconds.

Can SecScan AI operate in an air-gapped or high-security VPC?

Yes. SecScan AI natively supports local, air-gapped inference via Ollama and self-hosted model runners. Zero telemetry or code leaves your perimeter, making it fully compliant with SOC 2 Type II, ISO 27001, HIPAA, and defense-grade requirements.

What AI engines are supported out of the box?

As of release v2026.10.23, SecScanAI supports 8 interchangeable providers: OrcaRouter Cyber Inference, OpenAI, Anthropic Claude 3.5, Google Gemini 2.0, Groq (500 tok/s), DeepSeek V3, Mistral, and local Ollama instances with intelligent runtime failover.

How does SecScan AI conduct OWASP LLM Red Teaming?

Our AI Red Team harness runs automated adversarial probes against targeted generative AI applications. It tests against direct and indirect prompt injection, sensitive data leakage, vector database retrieval poisoning, and system role impersonation, providing actionable guardrail rules.
