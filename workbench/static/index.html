TRANSPARENT BY DESIGN
Know what was actually tested.
This preview runs native HTTP metadata checks, a synthetic authorization/data proof, and an optional digest-pinned Semgrep CE project scanner that uses repository-authored rules inside a read-only, network-disabled container. It also has coverage-aware retesting, evidence bundles and scanner-result trust contracts. Trivy, Nuclei, ZAP and Nmap remain parser-only or unsupported for execution. No arbitrary shell commands, external exploitation, credential extraction or persistence.
